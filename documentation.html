📚 Documentation Overview

This page consolidates all security-relevant documentation for Origin Protocol's bug bounty program. Researchers are strongly encouraged to review existing audit reports, the OUSD and OETH technical specifications, and the architecture diagrams before submitting a report.

Understanding the intended behaviour of the system is critical to identifying genuine vulnerabilities. Reports that describe behaviour that is working as intended, or that duplicate known issues already documented in past audits, will be closed as out of scope.

All official documentation is maintained on docs.ousd.com and in the origin-dollar GitHub repository. The resources below provide direct links to the most security-relevant sections.

🏗 Architecture Overview

Origin Protocol uses a layered architecture separating token logic, vault management, yield strategy execution, and governance. Each layer has distinct access controls and upgrade paths.

The Vault is the central component — it accepts deposits of backing stablecoins, mints OUSD, manages allocations to yield strategies, and handles redemptions. The Strategies are upgradeable proxy contracts that deploy capital into external DeFi protocols such as Aave and Convex.

🛡 Past Security Audits

Origin Protocol has undergone multiple security audits by reputable firms. All findings from these audits are considered known issues and are out of scope for this bug bounty program. Reviewing these reports is essential before submitting a vulnerability report.

The full list of audit reports is available at docs.ousd.com/security-and-risks/audits. Key auditors have included Trail of Bits, OpenZeppelin, Solidified, and Certora.

Key Areas Covered in Past Audits

  • OUSD token elastic supply (rebase) mechanism
  • Vault deposit, mint, redeem, and allocate functions
  • Strategy integrations with Aave V2/V3, Compound, and Convex
  • Governance timelock and multi-sig access controls
  • Price oracle integrations and staleness checks
  • Upgradeable proxy patterns and storage collision risks
